# Fase 0 — Comece aqui

## O que faz um analista de segurança Júnior?
Monitora alertas, faz triagem, investiga eventos, documenta e escala incidentes, apoia a resposta e melhora detecções.

## Áreas possíveis
SOC/Blue Team · DFIR · GRC/Compliance · AppSec · Cloud Security · Pentest (ofensiva)

## Diagnóstico rápido (marque o que você já sabe)
- [ ] Explico o modelo TCP/IP e o que é DNS/HTTP
- [ ] Uso o terminal Linux (ls, grep, ssh, permissões)
- [ ] Entendo Active Directory e logs do Windows
- [ ] Escrevo scripts simples (Bash/Python)
- [ ] Conheço CIA, MITRE ATT&CK e OWASP Top 10
- [ ] Já analisei um alerta ou log em SIEM

**0–1 marcados:** trilha do zero · **2–4:** pule o que já domina · **5–6:** foque em prática e portfólio

## Entregável da fase
Um arquivo `meu-plano.md` no seu GitHub com: objetivo, trilha escolhida, horas por semana e data-alvo.

- [ ] Escolhi a área em que quero começar (SOC/Blue Team é o foco deste guia)
- [ ] Escolhi minha trilha por perfil
- [ ] Defini quantas horas por semana vou estudar e uma data-alvo
