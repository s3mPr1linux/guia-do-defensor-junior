# Fase 1 — Base de TI

**Duração:** 2–3 meses · **Dedicação:** 8–10 h/semana · **Pré-requisito:** saber usar um computador com confiança.

> Sem base, alerta de segurança vira ruído. Quem entende como a rede, o Linux e o Windows funcionam **enxerga o que é anormal**.

## Como estudar cada módulo
1. **Teoria curta** (vídeo/leitura) — no máximo 40% do tempo.
2. **Prática no lab** — 60% do tempo, mão na massa.
3. **Anotação** — resuma no seu repositório `fundamentos-lab`.
4. **Mini-projeto** — entregável do módulo.

## Perfis: o que pular
- **Suporte/Help Desk:** revise redes e vá direto para Linux.
- **Sysadmin:** faça só os checklists de cada módulo e foque em scripting.
- **Desenvolvedor:** foque em redes, Windows/AD e Linux.
- **Do zero:** siga tudo na ordem.

## Checklist final da fase

## Entregável da fase
