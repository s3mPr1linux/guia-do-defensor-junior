# Como contribuir

1. Abra uma **issue** descrevendo a proposta (ou pegue uma `good first issue`).
2. Faça um fork e crie uma branch: `feat/fase-3-triagem-phishing`.
3. Siga os templates (fase, lab, recurso).
4. Abra o Pull Request usando o template.

## Regras de conteúdo
- Português claro, sem jargão desnecessário; explique siglas na primeira vez.
- Todo link deve ter descrição e indicar se é **gratuito** ou **pago**.
- Labs: somente ambientes próprios/isolados. Nada de alvos reais.
- Ética primeiro: conteúdo ofensivo só com foco em entender a defesa.
- Não copie material protegido; referencie e resuma com suas palavras.
