# Cheatsheet — "Qual solução resolve este cenário?"

| Cenário | Solução |
|---|---|
| Exigir MFA só fora da rede corporativa | Acesso Condicional |
| Administrador com privilégio por 2 horas, com aprovação | Entra PIM |
| Detectar login de local impossível e senha vazada | Entra ID Protection |
| Revisar a cada trimestre quem acessa um app crítico | Revisões de acesso (ID Governance) |
| App Azure acessa banco sem senha no código | Identidade gerenciada |
| Sincronizar usuários do AD local com a nuvem | Entra Connect / Cloud Sync |
| Bloquear RDP da internet para uma sub-rede | NSG |
| Filtrar saída por nome de domínio, com inspeção central | Firewall do Azure |
| Proteger site contra SQL injection e XSS | WAF |
| Mitigar ataque volumétrico a IP público | Proteção contra DDoS |
| Administrar VM por RDP sem expor porta pública | Azure Bastion |
| Guardar chave de criptografia e string de conexão | Key Vault |
| Ver nota de postura e recomendações da nuvem | Defender para Nuvem (CSPM) |
| Proteger servidores e bancos com detecção de ameaças | Defender para Nuvem (proteção de cargas) |
| Correlacionar logs e automatizar resposta | Microsoft Sentinel |
| Caçar ameaças com consultas KQL | Sentinel / caça avançada do Defender |
| Proteger e-mail contra phishing e anexos maliciosos | Defender para Office 365 |
| Detectar malware e investigar endpoints | Defender para Ponto de Extremidade |
| Descobrir uso de apps SaaS não autorizados | Defender para Aplicativos de Nuvem |
| Detectar movimento lateral em controladores de domínio | Defender para Identidade |
| Priorizar vulnerabilidades e configurações inseguras | Gerenciamento de Vulnerabilidades do Defender |
| Pesquisar infraestrutura e atores de ameaça | Defender Threat Intelligence |
| Baixar relatório de auditoria do serviço | Portal de Confiança do Serviço |
| Avaliar conformidade com uma norma | Gerenciador de Conformidade |
| Impedir envio de cartões de crédito por e-mail | DLP |
| Marcar documento como "Confidencial" com criptografia | Rótulo de confidencialidade |
| Guardar contratos por 7 anos e depois excluir | Política/rótulo de retenção |
| Declarar documentos como registros imutáveis | Gerenciamento de registros |
| Investigar funcionário copiando dados antes de sair | Gerenciamento de riscos internos |
| Pesquisar e reter e-mails para caso jurídico | eDiscovery |
| Saber quem acessou/alterou um arquivo e quando | Auditoria |
